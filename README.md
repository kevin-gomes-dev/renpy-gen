Custom code to create a code generator for renpy, very basic and cannot handle choices fluently. Optimized to not have unnecessary shows and hides, and allows for custom python code via special pre-defined (or user defined) markers. Markers also allow for scene changes among other features (can easily extend in code)

Format expected for dialogue can be seen in dialogue.txt. In future, the regex should be user defined such that any format of dialogue is acceptable.

If the format of your dialogue is invalid, the script will tell you and suggest where to look.

To use: Clone, change driver code for your characters, file locations, etc.
